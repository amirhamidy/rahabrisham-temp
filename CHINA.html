// 新丝绸之路控股集团介绍及未来展望
  • 新丝绸之路控股集团旨在推动全球转型发展，目标是在国家经济中实现可持续变革，并提高农业、畜牧业和水产养殖业的效率。该集团成立于 1402 年 Azar 月（约公历 2023 年 11/12 月），注册资本为 2 万亿里亚尔，并着眼于长远未来。
    在短时间内，集团获得了必要的许可证，成为该国畜牧投入品供应的主要参与者之一。
    在新丝绸之路，我们相信粮食安全是现代社会最关键的需求之一，我们努力通过在相关行业建立价值链，以最高质量满足这一需求。
    从生产壳聚糖和益生菌家禽饲料等知识密集型产品，到利用先进技术设计和实施创新项目，所有这些都是为了实现这一宏伟目标。
  • 我们的愿景超越国界。我们正努力通过发展国际合作，包括与 CP 集团等实体建立伙伴关系，将世界领先的知识和技术引入国内，并将伊朗打造成该地区农牧产品生产的杰出枢纽。
  • 我们的目标不仅仅是提高产量，更要改善产品质量、减少浪费，并提高整个生产链各个环节的效率。
    这种方法使我们不仅能够以最佳方式满足国内需求，还能在全球市场上占据重要地位。
  • 新丝绸之路控股集团的组织价值观
  • 1. 创新与技术驱动：在当今世界，创新是进步的关键。在新丝绸之路，我们始终寻求利用最新技术和创造性解决方案来应对农业和畜牧业面临的挑战。
  • 2. 可持续发展承诺：环境可持续性和可持续发展是我们的基本价值观。我们所有的活动都旨在保护自然资源和支持子孙后代。

  • 种鸡养殖场

    随着人口增长和对蛋白质产品需求的增加，家禽养殖业已成为保障国家粮食安全的重要支柱之一。在此背景下，提供高质量、抗病力强的一日龄雏鸡，直接影响着肉鸡和蛋鸡养殖场的绩效。“在霍沙布（Khushab）建立全国最大的种鸡养殖场和一日龄雏鸡生产基地”是一个国家级战略项目，旨在满足国内需求并拓展国家出口能力。该养殖场将在霍沙布县工业园区建设，利用先进的技术知识和基础设施，将在保障国家鸡肉和鸡蛋生产链方面发挥重要作用。

    项目必要性与重要性

    伊朗是该地区最大的鸡肉生产国之一，但提供高质量的一日龄雏鸡一直是该行业的主要挑战之一。一些养殖场对进口一日龄雏鸡的依赖以及价格波动给生产商带来了诸多问题。在这种情况下，建设一个大型现代化养殖场，生产抗病、健康、标准的一日龄雏鸡，不仅能满足国内需求，还能为向周边国家出口创造条件。

    该项目的优势：

    1. 减少对进口一日龄雏鸡的依赖，满足国内养殖场需求

    2. 通过生产抗病、标准的雏鸡，提高家禽业的生产效率

    3. 在霍沙布地区创造可持续就业，促进地方经济发展

    4. 提升伊朗在区域和国际市场上的竞争力

    5. 改善国家粮食安全，减少鸡肉和鸡蛋市场的波动

    项目目标

    短期目标：

    1. 建设一个现代化、工业化的种鸡养殖综合体

    2. 为养殖场配备先进的环境和卫生控制系统

    3. 生产具有改良品种、抗病能力强的一日龄雏鸡

    4. 建立质量控制实验室和遗传管理系统，以改善种鸡群的性能

    长期目标：

    1. 满足国内约 30% 的一日龄雏鸡需求

    2. 拓展向伊拉克、阿富汗、土库曼斯坦及其他波斯湾沿岸国家出口一日龄雏鸡的能力

    3. 通过提高所产雏鸡的质量，降低鸡肉和鸡蛋的生产成本

    4. 建立包括种鸡场、孵化场和专用饲料厂在内的可持续生产链

    5. 参与品种改良研究，开发新的家禽品系，以提高性能和降低饲料消耗

    项目技术规格

    生产能力：

    1. 每批次超过 50 万只种鸡

    2. 年产约 1 亿只一日龄雏鸡

    项目基础设施：

    1. 所需土地：霍沙布工业园区内超过 20 公顷土地

    2. 养殖舍：数个配备智能通风、供暖和制冷系统的鸡舍

    3. 孵化单位：具有高生产能力并使用先进孵化设备的孵化场

    4. 遗传与质量控制实验室：用于监测种鸡健康和改善品种特性

    5. 管理与培训部门：培养家禽养殖管理方面的专业人才

    采用的技术

    1. 自动化系统：使用自动化系统控制养殖舍内的温度、湿度和通风

    2. 先进孵化设备：这些设备高精度地为胚胎发育提供最佳条件

    3. 智能管理：使用管理软件监控种鸡和雏鸡的性能

    4. 环保技术：空气净化和废物管理系统以减少污染

    一日龄雏鸡生产流程

    一日龄雏鸡的生产是一个多阶段的过程，从选择种鸡到将雏鸡运往市场。

    1. 种鸡的选择与饲养：

    • 选择性能优良、遗传抗性好、生产效率高的品种

    • 在完全标准化和受监控的条件下饲养种鸡

    • 制定营养和卫生计划以提高种蛋质量

    2. 种蛋的收集与储存：

    • 每天从种鸡舍收集种蛋

    • 在标准的温度和湿度条件下储存，以保持孵化能力

    3. 孵化过程：

    • 将种蛋放入孵化器和出雏器中

    • 控制温度、湿度和通风以提高出雏率

    • 在运往市场前监测雏鸡的健康和质量

    4. 一日龄雏鸡的运输与分销：

  • 蛋鸡养殖基地

    鉴于蛋白质供应的重要性以及鸡蛋作为家庭菜篮子中最重要营养来源之一的作用，建立全国最大的蛋鸡养殖基地，拥有 100 万只蛋鸡的产能和日产 100 万枚鸡蛋的能力，是满足国内需求、减少对进口的依赖和发展出口能力的关键一步。该基地将在霍沙布（Khushab）县建设，作为该地区最大、最现代化的鸡蛋生产场之一，将在生产、卫生和包装方面遵守全球标准。

    项目必要性与重要性

    鸡蛋作为最便宜、最丰富的蛋白质来源之一，在国家粮食安全中起着至关重要的作用。据统计，伊朗年产鸡蛋超过 100 万吨，是该地区该产品的主要生产国之一。然而，我们仍然面临价格波动、供应短缺、部分地区依赖进口以及需要提高生产质量等挑战。

    1. 提高国内生产能力，防止国内鸡蛋短缺

    2. 消除对进口的依赖，增强伊朗的出口能力

    1. 成为国家和地区主要的鸡蛋供应中心

    4. 提升生产标准，减少家禽养殖场常见的疾病

    • 控制鸡蛋质量并自动收集

    3. 包装与分销：

    • 根据重量、质量和卫生标准对鸡蛋进行分类

    • 使用标准、坚固的纸箱包装，以实现最佳运输

    • 通过零售连锁店、餐馆和出口渠道分销产品

    4. 有助于稳定市场鸡蛋价格，减少价格波动

    奉至仁至慈的真主之名

    “哦，转变心灵与眼光的主宰！哦，掌管黑夜与白昼的主宰！哦，变换境况与情势的主宰！求您将我们的境况转变为最佳的境况。”

    新年伊始恰逢盖德尔夜和信士的长官（愿主福安之）殉难日。我们希望这些夜晚的福祉以及敬畏者的领袖（愿主福安之）的关怀，在这一年里能够惠及我们亲爱的人民、我们的民族、我们的国家以及所有以诺鲁孜节开启新年的人们。

    1403年是多事之秋。这一年接连发生的事件，类似于1360年的事件，给我们亲爱的人民带来了困难和艰辛。年初，深受伊朗人民爱戴的总统，已故的莱希先生（愿主怜悯之）殉难。在此之前，我们的一些顾问在大马士革殉难。此后，德黑兰和黎巴嫩又发生了各种事件，伊朗民族和伊斯兰民族失去了宝贵的人才。这些都是发生的痛苦事件。此外，在这一年中，特别是在下半年，经济问题给人民带来了压力，民生困难给人民制造了问题。这些困难在今年一直存在；但与此同时，出现了一个伟大而奇特的现象，那就是伊朗民族意志的力量、伊朗民族的精神面貌、伊朗民族的团结以及伊朗民族的高度准备状态得以展现。首先，面对总统逝世这样的事件，人民举行的盛大送别仪式、人民喊出的口号、人民展现出的高昂士气表明，这场灾难虽然沉重，但未能使伊朗民族感到软弱。随后，他们在法定期限内迅速举行了选举，选出了新总统，组建了政府，使国家管理摆脱了真空状态。这些都非常重要，显示了伊朗民族的高昂士气、强大能力和精神力量。我们应为此感谢真主。

    此外，在最近几个月的事件中，我们在黎巴嫩的许多兄弟——我们的宗教兄弟和黎巴嫩兄弟——遇到了困难，伊朗民族能够以宽广的胸怀向他们伸出援手。在这方面发生的事件，即人民以惊人的方式向他们的黎巴嫩和巴勒斯坦兄弟提供大量援助，是我国历史上令人难忘的事件之一。我们的女士们、妇女们慷慨地捐出自己的黄金，以及我们的人民、我们的男人们所提供的帮助，这些都是重要的事情。这显示了民族的意志力和坚定决心。这种精神、这种参与、这种准备、这种精神力量是我们亲爱的伊朗未来和永恒生活的资本。国家将最大限度地利用这一资本，真主也将继续施恩于这个民族，愿主意欲。

    去年，我们提出了“依靠人民参与实现生产飞跃”的口号，这对国家来说是必要的，甚至在某种意义上是至关重要的。1403年的各种事件阻碍了这一口号的完全实现。当然，也付出了良好的努力；政府、人民、私营部门、投资者、企业家，他们都能够做出好的工作，但所发生的与预期仍有差距。因此，今年我们的主要问题仍然是经济问题。我今年向尊敬的政府、尊敬的官员和我们亲爱的人民提出的期望，仍然是一个经济问题。这个经济问题也将是我们今年的口号，它关系到经济投资。

    国家经济的重要问题之一是生产性投资。只有进行了投资，生产才能实现飞跃。当然，投资主要应由人民进行——政府应规划其不同方式——但在人民没有动力或没有能力投资的地方，政府也可以进入这个领域；不是与人民竞争，而是作为人民的替代者；在人民不参与的地方，政府应进入并进行投资。无论如何，生产性投资是国家经济和解决人民生计问题的必要问题之一。改善人民生计需要规划，但没有诸如此类的前提条件，这种规划是不可能实现的。政府和人民都必须以巨大的决心和动力，认真对待并追求为生产而投资。政府的工作是创造条件，消除生产障碍；人民的工作是能够将他们的小额和大额资本用于生产。如果资本用于生产，就不会流向购买黄金、购买外汇等有害活动，有害活动就不会发生。中央银行可以在这方面发挥作用，政府也可以创造许多有效的作用。因此，今年的口号是“为生产投资”，愿主意欲，这将为人民的生计带来转机，政府的规划与人民的参与相结合，愿主意欲，将解决问题。

    我还要提及最近几天的事件。篡夺者犹太复国主义政权再次袭击加沙是一项巨大的、灾难性的罪行。伊斯兰民族必须团结一致地反对它。他们应该搁置在各种问题上的分歧。这是伊斯兰民族的问题。此外，全世界所有自由的人们，在美国、在西方和欧洲国家以及其他国家，人民都应认真反对他们正在进行的这种背信弃义和灾难性的行动。儿童再次被杀害，房屋被摧毁，人民流离失所，人民必须阻止这场灾难。当然，美国也是这场灾难的共犯。世界上有政治见解的人都 تشخیص [tashkhis - discern/diagnose] 到，这件事是在美国的示意下，或者至少是在美国的同意和绿灯下进行的。因此，美国也是这一罪行的同谋。也门的事件也是如此；对也门人民、也门平民的袭击也是一种罪行，必须予以制止。

    我们希望全能的真主在新的一年里为伊斯兰民族注定带来福祉、安康与胜利，伊朗民族也能够以喜悦、满意、完全团结和成功，愿主意欲，开始并推进现在开始的这一年，直到年底。

    我希望瓦利·阿斯尔（愿我们的灵魂为他牺牲）的神圣之心、伟大伊玛目的纯洁灵魂以及烈士们的高尚灵魂对我们感到满意和喜悦。

    愿真主的平安、慈悯和吉庆在你们上。

  • 外汇分配不足威胁食用油市场

    经济论坛：伊朗植物油工业行业协会主席阿里·法泽利表示：植物油厂对政府的外汇应收款项问题已经严重到一些工厂甚至还没有收到去年春季和夏季的外汇应收款。考虑到全球价格上涨和行业内流动性短缺，这种情况实际上是不可持续的。

    据Mehr通讯社报道，他补充说：长期拖延支付工厂的外汇应收款，不仅给生产带来了巨大的财务成本，还降低了它们再次进口毛油的财务能力和外汇信誉，这意味着未来的进口和生产将会减少。

    法泽利宣布，未支付已购买的外汇是植物油行业面临的新问题，并继续说道：除了支付外汇的周期延长之外，一些工厂在等待数月的外汇分配后，成功获得了外汇分配，并支付了购买外汇的里亚尔，但不幸的是，他们购买的外汇尚未支付。

    据伊朗植物油工业行业协会主席称，农业部事务流程极其缓慢以及缺乏足够的人力来响应，是当前植物油厂面临的其他问题。

  • 揭示伊朗经济持续通胀的原因

    是什么厄运扼住了伊朗经济的咽喉？

    扎赫拉·阿里阿克巴里报道 - 伊朗经济多年来一直面临两位数的通货膨胀，以至于一些估计表明，伊朗拥有世界上持续时间最长的通货膨胀。

    伊朗自伊斯兰历1350年代初（公历1970年代初）开始面临通货膨胀，并且通胀率一直居高不下。

    根据这份报告，在所有这些年里，伊朗的通货膨胀率仅在少数几年内降至个位数，而在其他年份，通货膨胀率一直是两位数。重要的一点是，近年来通货膨胀的性质经历了显著变化。通货膨胀率现已进入百分之四十的区间。这种高通胀率导致中产阶级的生活状况恶化。

    伊朗通货膨胀的重要原因是什么？

    伊朗通货膨胀的重要原因是什么？这是许多专家在过去几年中已经回答过的问题。伊朗的通货膨胀率之所以高，是由于财政和货币纪律松弛，这体现在预算赤字上。预算赤字是伊朗年度预算不可分割的一部分。

    根据这份报告，伊朗制定的第一个预算草案，在卡扎尔王朝末期，也面临预算赤字。

    伊朗历史上第一个官方预算，与伊斯兰历1299年（公历1920/1921年）的萨尼·奥·杜勒·赫达亚特（Sani-ol-Dowleh Hedayat）内阁有关。其收入估计为14,116,600托曼，支出估计为14,618,000托曼，有趣的是，伊朗的第一个预算也有赤字，数额为50万托曼。其主要收入来源是农业部门的税收。

    伊朗制定的最新预算，即1403年的预算，仍然面临预算赤字。尽管政府认为议会对预算草案进行的修改是导致400万亿托曼预算赤字的原因，但1403年的预算草案曾因其隐含的预算赤字而被伊斯兰议会否决过一次。

    政府为克服预算赤字而必须采取的解决方案，通常只会导致通货膨胀。尽管近年来由于法律禁止，政府没有执行向中央银行借款，但这种借款的途径已经变得间接，并且这种行动的后果间接地体现在经济中。

    发行货币、发行债券、责成银行承担政府开支、通过出售股份弥补赤字……所有这些只会给经济带来通货膨胀。

    当政府过于庞大时

    迈赫迪·帕祖基认为预算赤字是国家规模庞大的结果。他在接受通讯社采访时强调：我们管理国家的成本很高。这种高昂的管理成本导致伊朗经济面临严重危机。我们可以通过财政和货币纪律来关闭伊朗的通货膨胀制造机，但只要我们的估计与我们的实际表现之间存在差距，我们就会面临这种情况。

    他说：不幸的是，尽管存在现有的制约因素，我们仍然面临着国家资金被花费在不该花费的地方的问题。而财政纪律，加上对伊朗经济能力的准确评估，可以解决这个问题。

    帕祖基指的是伊朗政府面临的一种奇怪的理想主义。这种雄心壮志和遥远的愿望当然也可以在发展计划中被追踪到。发展计划中制定了大量目标，但实际上没有一个能够实现。控制通货膨胀和进入个位数通货膨胀也是这些目标之一，尽管伊朗已经开始了第七个发展计划，但尚未取得成果。

    沙希德·查姆兰大学（Shahid Chamran University）的教员莫尔塔扎·阿夫加赫（Morteza Afgheh）在接受Khabaronline通讯社采访时也证实了这一理论，并表示伊朗政府过于庞大，大量亏损公司以及对公司的非经济管理和对经济结构的不重视，为通货膨胀的发生创造了条件。

    伊玛目萨迪克大学（Imam Sadiq University）经济学教授卡姆兰·纳德里（Kamran Nadri）也认为，消除通货膨胀需要一种机制，而这种机制在伊朗经济中尚未出现。

    他认为，经济信号应该表明政府有控制通货膨胀的计划。这些信号包括控制预算赤字、恢复财政和货币纪律，以及根据经济能力调整预算。

    看来，只要预算赤字的厄运之脚还踩在伊朗经济的咽喉上，伊朗的通货膨胀就将持续高企。

  • 鸡蛋日产量3900吨/每板价格多少？

    经济论坛：祖国养鸡者联盟（Mihan Poultry Farmers Union）董事会主席宣布，为调节市场，自伊斯兰历12月（Esfand）初以来已支持性收购了1万吨鸡蛋。

    据青年记者俱乐部报道，祖国养鸡者联盟董事会主席哈米德礼萨·卡沙尼表示：根据统计，自伊斯兰历12月初至今，为调节市场，已按每公斤58,500托曼的价格从养鸡户手中支持性收购了1万吨过剩鸡蛋。

    他宣布目前养鸡场门口每公斤鸡蛋的价格为54,000至55,000托曼，并补充说：通过在斋月结束前进行支持性收购，我们力求维持市场当前价格，但在斋月之后，我们要求根据生产成本调整价格。

    关于鸡蛋出口的最新情况，卡沙尼表示：根据统计，自年初至今，已向目标市场出口了15.5万吨鸡蛋，预计到年底将达到16万吨。

    祖国养鸡者联盟董事会主席宣布，鸡蛋日产量为3800至3900吨，并补充说：据估计，今年的鸡蛋产量将达到137万吨。

    他宣布，消费者购买每枚鸡蛋的合理价格为4,500托曼，并表示：向消费者供应的每板（通常指30枚）鸡蛋的合理价格为140,000托曼。
